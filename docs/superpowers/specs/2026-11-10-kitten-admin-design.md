# 幼貓管理後台（原型階段）設計

日期：2026-11-10

## 目標
讓貓舍主人不碰程式碼，就能新增一胎、新增／編輯／刪除幼貓、切換狀態（可預約／已預訂／已送養）、控制整胎上下架，並直接更新 GitHub Pages 上的網站。

## 資料
- 唯一正本：`data/site.json`（`cats`、`litters`、`kittens`、`updated`）。
- 前台 `index.html` 載入時 fetch 這個檔；`published: false` 的胎與其幼貓不顯示；種貓頁的後代由胎資料推算。
- 照片放 `img/`（從 `prototype/img` 搬到根目錄）；後台上傳的照片放 `img/kittens/<slug>-<時間戳>.jpg`。建置腳本不再覆蓋 `img/`。

## 後台 `admin.html`
- 單頁、無框架，沿用前台 token，字級 14px、列高 44px，手機單欄。
- 分頁：幼貓管理、種貓管理、設定。
- 種貓管理：分種公／種母兩組列表；表單含照片、名字（必填）、身分、登錄名、花色、出生日（必填）、血型、介紹、檢測列表（項目／結果／日期地點）、文件列表。已有胎使用的種貓不能刪除。新增一胎的爸媽選單來自種貓資料。
- 幼貓管理：以胎分組（最新在上），每胎有上架開關與「編輯這一胎」；每隻幼貓一列，右側三段式狀態按鈕點一下即切換；點名字開編輯面板；每胎底部「新增幼貓到這一胎」。
- 新增一胎：母貓、父貓、出生日（必填）、預計離家日（預設出生後 12 週）、是否顯示。胎號 `L<年><字母>` 與季節自動產生。新胎預設不上架。
- 幼貓表單：照片（瀏覽器端縮到 1000px、JPEG 0.82）、名字（必填）、性別、花色（含常見花色建議）、狀態、一句話、四個檢查項目。刪除需按兩次。
- 草稿：所有修改先進記憶體並存 localStorage（`qiqi-admin-draft`），重新整理可還原；底部列顯示未發佈項數，可捨棄或發佈。
- 發佈：先 PUT 待上傳照片，再 PUT `data/site.json`（帶 sha；409/422 時重抓 sha 重試一次）。成功後清草稿並提示約一分鐘生效。
- 金鑰：GitHub fine-grained token（只限本倉庫、Contents 讀寫），存 localStorage（`qiqi-admin-token`）。無金鑰可改草稿但不能發佈。

## 不在範圍
公告、詢問信箱管理；帳號密碼登入；多人同時編輯的合併。
